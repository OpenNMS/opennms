
= Groups

WARNING: This API is deprecated in {page-component-title} 37 and will be removed in {page-component-title} 38.
Use the xref:development:rest/groups_v2.adoc[Groups (v2)] API at `/api/v2/groups` instead.

Groups are stored in the database.
The write operations need the `ROLE_ADMIN` role, like the v2 API, and answer `403` without it; `ROLE_REST` is not enough.
This includes the category authorizations of a group, also when they are changed through `/categories/\{category}/groups/\{group}`.
They check the data like the v2 API does:

* A new group name must not be reserved or look like `Admin`, must fit its column, and must not contain markup, whitespace or any of `: / \ % ? #`.
  The response is `400`.
* Comments must not contain markup (stored comments are accepted unchanged).
  Every member of a group must be an existing user, named once and not blank.
  The response is `400`.
* A form `PUT` accepts only the keys `comments` and `users`, spelled exactly.
  Any other key is refused before anything is changed.
  The response is `400`.
  For `name`, in any case, it points to `PUT /api/v2/groups/\{name}/rename`.
* The `Admin` group cannot be deleted.
  The response is `400`.
* A group that is the membership group of an on-call role or a target of a notification destination path cannot be deleted.
  The response is `409`.
* A save that races with another change, or is based on stale data, answers `409`.
* A save through this API keeps the duty schedules and the default map of the stored group.
* A caller without `ROLE_ADMIN` sees `xxxxxxxx` in place of the password hash of every user but their own in `/groups/\{groupname}/users`.

== GETs (reading data)

[caption=]
.Groups API GET functions
[options="autowidth"]
|===
| Resource  | Description

| /groups
| Get a list of groups.

| /groups/\{groupname}
| Get a specific group, given a group name.

| /groups/\{groupname}/users
| Get the users for a group, given a group name.

| /groups/\{groupname}/users/\{username}
| Get a specific user in a group, given a group name and username.

| /groups/\{groupname}/categories
| Get the categories associated with a group, given a group name.

| /groups/\{groupname}/categories/\{categoryname}
| Get a specific category associated with a group, given a group name and category name.
|===

== POST (adding data)

[caption=]
.Groups API POST function
[options="autowidth"]
|===
| Resource  | Description

| /groups

|===

== PUTs (modifying data)

[caption=]
.Groups API PUT functions
[options="autowidth"]
|===
| Resource  | Description

| /groups/\{groupname}
| Update the metadata of a group (for example, change the `comments` field).

| /groups/\{groupname}/users/\{username}
| Add a user to the group, given a group name and username.

| /groups/\{groupname}/categories/\{categoryname}
| Associate a category with the group, given a group name and category name.
|===

== DELETEs (removing data)

[caption=]
.Groups API DELETE functions
[options="autowidth"]
|===
| Resource  | Description

| /groups/\{groupname}
| Delete a group.

| /groups/\{groupname}/users/\{username}
| Remove a user from the group.

| /groups/\{groupname}/categories/\{categoryname}
| Disassociate a category from a group, given a group name and category name.
|===
