
= WebMonitor
:description: Learn how to configure and use the WebMonitor in OpenNMS {page-component-title} for performing HTTP connections using Apache HttpClient.

WebMonitor is a clone of <<service-assurance/monitors/HttpMonitor.adoc#poller-http-monitor, HttpMonitor>>, that uses a different underlying library for doing HTTP connections.
WebMonitor uses Apache HttpClient, which acts more like a real browser (follows redirects, and so on) than HttpMonitor.

== Monitor facts

[cols="1,7"]
|===
| Class Name
| `org.opennms.netmgt.poller.monitors.WebMonitor`
|===

== Configuration and use

.Optional configuration parameters
[options="header"]
[cols="2,3,2"]
|===
| Parameter
| Description
| Default

| use-system-proxy kbd:[{}]
| Specifies that system-wide proxy settings be used.
| false

| scheme
| Protocol/scheme to use.
| http, https

| port
| The port to connect to.
| 80

| path
| The path of the URL to request (for example, `/store/index.html`).
| n/a

| queryString
| The query string to add to the URL after a `?` (for example, foo=bar&baz=zot).
| n/a

| timeout
| The connection/socket timeout in milliseconds.
| 3000

| user-agent
| The User-Agent: header to send.
| OpenNMS WebMonitor

| virtual-host
| The Host: header to send.
| n/a

| http-1.0
| True/false whether to use HTTP 1.0 or 1.1.
| false

| header_<n>
| Name of an additional header to include in the request, where `<n>` is a number (the parameter name must match `header_[0-9]+$`).
Set the header value with a matching `header_<n>_value` parameter.
| n/a

| use-ssl-filter
| Defaults to false. If true, it will trust self-signed certificates.
| false

| auth-enabled
| Whether to enable basic authentication.
| n/a

| auth-user
| The username for basic authentication.
| n/a

| auth-password
| The password
| n/a

| auth-preemptive
| Whether to send basic authentication even if the site did not ask for it.
| true

| response-text
| Text that the response body is checked against.
Without a leading `~`, the whole response body must equal the value.
With a leading `~`, the rest of the value is a Java regular expression that must match the whole response body.
When this parameter is set, its result replaces the `response-range` check.
| n/a

| response-range
| A single range of HTTP status codes, in the form `<low>-<high>`, that is considered a success.
| 100-399
|===

kbd:[{}] _indicates the parameter supports <<reference:service-assurance/introduction.adoc#ref-service-assurance-monitors-placeholder-substitution-parameters, placeholder substitution>>._

The monitor makes a single attempt per poll and does not use the `retry` parameter.

== Examples

The following example requests `https://<interface-address>/status` with a custom `Host` header and an extra `Accept` header.
The service is up when the response body contains `OK`.
Note that you must include the `monitor` section for each service in your definition.

[source, xml]
----
<service name="Web-Status" interval="300000" user-defined="false" status="on">
  <parameter key="timeout" value="5000"/>
  <parameter key="scheme" value="https"/>
  <parameter key="port" value="443"/>
  <parameter key="path" value="/status"/>
  <parameter key="virtual-host" value="www.example.com"/> <1>
  <parameter key="use-ssl-filter" value="true"/> <2>
  <parameter key="header_0" value="Accept"/> <3>
  <parameter key="header_0_value" value="text/plain"/> <3>
  <parameter key="response-range" value="200-299"/> <4>
  <parameter key="response-text" value="~(?s).*OK.*"/> <5>
</service>

<monitor service="Web-Status" class-name="org.opennms.netmgt.poller.monitors.WebMonitor"/>
----
<1> Value of the `Host` header.
<2> Trust self-signed certificates.
<3> Header name and value, paired by the number in the parameter name.
<4> Applies only when `response-text` is not set; here the `response-text` result replaces it.
<5> The leading `~` marks a regular expression; `(?s)` lets `.*` span line breaks in the body.

The following example uses preemptive basic authentication against a page that requires a login:

[source, xml]
----
<service name="Web-Admin" interval="300000" user-defined="false" status="on">
  <parameter key="port" value="8080"/>
  <parameter key="path" value="/admin/"/>
  <parameter key="auth-enabled" value="true"/>
  <parameter key="auth-user" value="monitor"/>
  <parameter key="auth-password" value="secret"/>
  <parameter key="response-range" value="200-299"/>
</service>

<monitor service="Web-Admin" class-name="org.opennms.netmgt.poller.monitors.WebMonitor"/>
----
