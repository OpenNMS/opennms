= Disk Usage Detector
:description: Learn how the DiskUsageDetector in OpenNMS {page-component-title} finds storage entries in the HOST-RESOURCES-MIB over SNMP.

The DiskUsageDetector finds storage entries, such as file systems, over SNMP.
It walks the `hrStorageDescr` table of the HOST-RESOURCES-MIB and detects the service when an entry matches the `disk` parameter.
Use it together with the xref:service-assurance/monitors/DiskUsageMonitor.adoc[DiskUsageMonitor].

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.snmp.DiskUsageDetector`
|===

== Configuration and use

The DiskUsageDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the DiskUsageDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

3+| *Required*

| disk
| Storage description to look for, for example `/`.
| none

3+| *Optional*

| matchType
| How `disk` is compared to each storage description.
Valid values are `exact`, `startswith`, `endswith`, and `regex`.
With `regex`, the pattern can match any part of the description.
| exact

| hrStorageDescr
| OID of the table that holds the storage descriptions.
| .1.3.6.1.2.1.25.2.3.1.3

| port
| SNMP port.
Overrides the port from the SNMP configuration for the interface.
| from SNMP configuration

| timeout
| SNMP timeout, in milliseconds.
Overrides the timeout from the SNMP configuration.
| from SNMP configuration

| retries
| Number of SNMP retries.
Overrides the retries from the SNMP configuration.
| from SNMP configuration

| forceVersion
| SNMP version to use instead of the configured one.
Valid values are `v1`, `v2c`, and `v3`.
| from SNMP configuration
|===

The detector reads the SNMP agent settings for the interface from the SNMP configuration.
The `port`, `timeout`, `retries`, and `forceVersion` parameters override them for detection only.

== Example configuration

The following detector finds the root file system of Linux hosts:

[source, xml]
----
<detector name="DiskUsage-root" class="org.opennms.netmgt.provision.detector.snmp.DiskUsageDetector">
    <parameter key="disk" value="/"/>
    <parameter key="matchType" value="exact"/>
</detector>
----
