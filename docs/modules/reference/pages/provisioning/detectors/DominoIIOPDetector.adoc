= Domino IIOP Detector
:description: Learn how the DominoIIOPDetector in OpenNMS {page-component-title} finds Lotus Domino IIOP services.

The DominoIIOPDetector finds Lotus Domino servers that offer the Internet Inter-ORB Protocol (IIOP).
It requests `/diiop_ior.txt` over HTTP on the port set in `iorPort`, and detects the service when the content starts with `IOR:`.
The detector does not open a connection to the IIOP port itself.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.DominoIIOPDetector`
|===

== Configuration and use

The DominoIIOPDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the DominoIIOPDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| iorPort
| HTTP port the detector uses to request `/diiop_ior.txt`.
| 80

| port
| IIOP port of the service.
The detector does not connect to this port.
| 63148
|===

== Example configuration

The following detector requests the IOR file from a Domino HTTP server on port 8080:

[source, xml]
----
<detector name="DominoIIOP" class="org.opennms.netmgt.provision.detector.simple.DominoIIOPDetector">
    <parameter key="iorPort" value="8080"/>
</detector>
----
