= LDAPS Detector
:description: Learn how the LdapsDetector in OpenNMS {page-component-title} finds LDAP over TLS services for monitoring in your network.

The LdapsDetector finds LDAP directory services that use implicit TLS.
It works like the xref:provisioning/detectors/LdapDetector.adoc[LdapDetector], but connects over TLS.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.LdapsDetector`
|===

== Configuration and use

The LdapsDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the LdapsDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port of the LDAPS service.
| 636
|===

== Example configuration

The following detector finds LDAPS services on the default port:

[source, xml]
----
<detector name="LDAPS" class="org.opennms.netmgt.provision.detector.simple.LdapsDetector">
    <parameter key="port" value="636"/>
</detector>
----
