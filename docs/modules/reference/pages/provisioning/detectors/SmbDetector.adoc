= SMB Detector
:description: Learn how the SmbDetector in OpenNMS {page-component-title} finds hosts that answer NetBIOS name queries.

The SmbDetector finds hosts that answer NetBIOS name queries, such as Windows file servers and Samba servers.
It queries the NetBIOS name of the interface address and detects the service when the returned name differs from the IP address.
The detector does not use the `port` or `timeout` parameters.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.smb.SmbDetector`
|===

== Configuration and use

The SmbDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the SmbDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| retries
| Number of retries after the first attempt.
| 0
|===

== Example configuration

The following detector finds SMB hosts in the `192.168.10.0/24` network only:

[source, xml]
----
<detector name="SMB" class="org.opennms.netmgt.provision.detector.smb.SmbDetector">
    <parameter key="ipMatch" value="192.168.10.*"/>
</detector>
----
