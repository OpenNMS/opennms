= PERC Detector
:description: Learn how the PercDetector in OpenNMS {page-component-title} finds Dell PERC RAID arrays over SNMP.

The PercDetector finds logical drives on Dell PowerEdge RAID Controllers (PERC) over SNMP.
It reads the logical drive status (`.1.3.6.1.4.1.3582.1.1.2.1.3`) for the configured array, and detects the service when the value is `2`.
Use it together with the xref:service-assurance/monitors/PercMonitor.adoc[PercMonitor].

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.snmp.PercDetector`
|===

== Configuration and use

The PercDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the PercDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| arrayNumber
| Instance suffix of the logical drive to check, appended to the status OID.
| 0.0

| port
| SNMP port.
Overrides the port from the SNMP configuration for the interface.
| from SNMP configuration

| timeout
| SNMP timeout, in milliseconds.
Overrides the timeout from the SNMP configuration.
| from SNMP configuration

| retries
| Number of SNMP retries.
Overrides the retries from the SNMP configuration.
| from SNMP configuration

| forceVersion
| SNMP version to use instead of the configured one.
Valid values are `v1`, `v2c`, and `v3`.
| from SNMP configuration
|===

The detector reads the SNMP agent settings for the interface from the SNMP configuration.
The `port`, `timeout`, `retries`, and `forceVersion` parameters override them for detection only.

== Example configuration

The following detector checks the second logical drive of the first adapter:

[source, xml]
----
<detector name="PERC-Array-1" class="org.opennms.netmgt.provision.detector.snmp.PercDetector">
    <parameter key="arrayNumber" value="0.1"/>
</detector>
----
