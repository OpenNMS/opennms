= SSH Detector
:description: Learn how the SshDetector in OpenNMS {page-component-title} finds SSH services for monitoring in your network.

The SshDetector finds SSH services for monitoring in your network.
It connects to the configured port, exchanges protocol identification banners, and detects the service when the server sends its banner.
You can require the server banner to match a regular expression.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.ssh.SshDetector`
|===

== Configuration and use

The SshDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the SshDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port to connect to.
| 22

| banner
| Regular expression that the server banner must contain.
A value of `*` matches any banner.
| none

| match
| Regular expression that the server banner must contain.
If set, it takes precedence over `banner`.
| none

| clientBanner
| Identification string the detector sends to the server.
| SSH-1.99-OpenNMS_1.5
|===

== Example configuration

The following detector finds OpenSSH servers only:

[source, xml]
----
<detector name="SSH" class="org.opennms.netmgt.provision.detector.ssh.SshDetector">
    <parameter key="port" value="22"/>
    <parameter key="banner" value="OpenSSH"/>
</detector>
----
