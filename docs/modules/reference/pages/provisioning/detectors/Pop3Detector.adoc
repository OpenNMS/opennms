= POP3 Detector
:description: Learn how the Pop3Detector in OpenNMS {page-component-title} finds POP3 services for monitoring in your network.

The Pop3Detector finds POP3 services for monitoring in your network.
It expects a banner that starts with `+OK`, sends `QUIT`, and detects the service when the reply also starts with `+OK`.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.Pop3Detector`
|===

== Configuration and use

The Pop3Detector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the Pop3Detector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port to connect to.
| 110

| idleTime
| Time, in milliseconds, that the detector waits for data from the service before it gives up.
The value is rounded to whole seconds, with a minimum of one second.
| 3000

| useSSLFilter
| Set `true` to use TLS for the connection.
| false
|===

NOTE: This detector opens connections with a fixed connection timeout of 2000 milliseconds and does not apply the `timeout` parameter.
Use `idleTime` to control how long it waits for responses.

== Example configuration

The following detector finds POP3 services on the default port:

[source, xml]
----
<detector name="POP3" class="org.opennms.netmgt.provision.detector.simple.Pop3Detector">
    <parameter key="port" value="110"/>
</detector>
----
