= IMAPS Detector
:description: Learn how the ImapsDetector in OpenNMS {page-component-title} finds IMAP over TLS services for monitoring in your network.

The ImapsDetector finds IMAP services that use implicit TLS.
It runs the same conversation as the xref:provisioning/detectors/ImapDetector.adoc[ImapDetector] over a TLS connection.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.ImapsDetector`
|===

== Configuration and use

The ImapsDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the ImapsDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port to connect to.
| 993

| idleTime
| Time, in milliseconds, that the detector waits for data from the service before it gives up.
The value is rounded to whole seconds, with a minimum of one second.
| 3000

| useSSLFilter
| Set `true` to use TLS for the connection.
| true
|===

NOTE: This detector opens connections with a fixed connection timeout of 2000 milliseconds and does not apply the `timeout` parameter.
Use `idleTime` to control how long it waits for responses.

== Example configuration

The following detector finds IMAPS services on the default port:

[source, xml]
----
<detector name="IMAPS" class="org.opennms.netmgt.provision.detector.simple.ImapsDetector">
    <parameter key="port" value="993"/>
</detector>
----
