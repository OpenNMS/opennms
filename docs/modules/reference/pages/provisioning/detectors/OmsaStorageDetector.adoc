= OMSA Storage Detector
:description: Learn how the OmsaStorageDetector in OpenNMS {page-component-title} finds online Dell OpenManage virtual disks over SNMP.

The OmsaStorageDetector finds virtual disks managed by Dell OpenManage Server Administrator (OMSA) over SNMP.
It reads `virtualDiskRollUpStatus` (`.1.3.6.1.4.1.674.10893.1.20.140.1.1.19`) for the configured virtual disk, and detects the service when the status is `3` (online).
Use it together with the xref:service-assurance/monitors/OmsaStorageMonitor.adoc[OmsaStorageMonitor].

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.snmp.OmsaStorageDetector`
|===

== Configuration and use

The OmsaStorageDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the OmsaStorageDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| virtualDiskNumber
| Index of the virtual disk to check.
| 1

| port
| SNMP port.
Overrides the port from the SNMP configuration for the interface.
| from SNMP configuration

| timeout
| SNMP timeout, in milliseconds.
Overrides the timeout from the SNMP configuration.
| from SNMP configuration

| retries
| Number of SNMP retries.
Overrides the retries from the SNMP configuration.
| from SNMP configuration

| forceVersion
| SNMP version to use instead of the configured one.
Valid values are `v1`, `v2c`, and `v3`.
| from SNMP configuration
|===

The detector reads the SNMP agent settings for the interface from the SNMP configuration.
The `port`, `timeout`, `retries`, and `forceVersion` parameters override them for detection only.

== Example configuration

The following detector checks the second virtual disk:

[source, xml]
----
<detector name="OMSA-Disk-2" class="org.opennms.netmgt.provision.detector.snmp.OmsaStorageDetector">
    <parameter key="virtualDiskNumber" value="2"/>
</detector>
----
