= IMAP Detector
:description: Learn how the ImapDetector in OpenNMS {page-component-title} finds IMAP services for monitoring in your network.

The ImapDetector finds IMAP services for monitoring in your network.
It connects to the configured TCP port, expects a banner that starts with `* OK`, sends a `LOGOUT` command, and detects the service when the server replies with `* BYE` and a tagged `OK`.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.ImapDetector`
|===

== Configuration and use

The ImapDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the ImapDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port to connect to.
| 143

| idleTime
| Time, in milliseconds, that the detector waits for data from the service before it gives up.
The value is rounded to whole seconds, with a minimum of one second.
| 3000

| useSSLFilter
| Set `true` to use TLS for the connection.
| false
|===

NOTE: This detector opens connections with a fixed connection timeout of 2000 milliseconds and does not apply the `timeout` parameter.
Use `idleTime` to control how long it waits for responses.

== Example configuration

The following detector finds IMAP services on the default port:

[source, xml]
----
<detector name="IMAP" class="org.opennms.netmgt.provision.detector.simple.ImapDetector">
    <parameter key="port" value="143"/>
</detector>
----
