= Cisco IP SLA Detector
:description: Learn how the CiscoIpSlaDetector in OpenNMS {page-component-title} finds active Cisco IP SLA operations over SNMP.

The CiscoIpSlaDetector finds active Cisco IP SLA operations over SNMP.
It reads the `rttMonCtrlAdminTag` (`.1.3.6.1.4.1.9.9.42.1.2.1.1.3`) and `rttMonCtrlOperState` (`.1.3.6.1.4.1.9.9.42.1.2.9.1.10`) tables of the CISCO-RTTMON-MIB.
It detects the service when an IP SLA operation has the configured tag and its operational state is `active(6)`.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.snmp.CiscoIpSlaDetector`
|===

== Configuration and use

The CiscoIpSlaDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the CiscoIpSlaDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

3+| *Required*

| adminTag
| Tag of the IP SLA operation, as configured with the `tag` command on the router.
| none

3+| *Optional*

| port
| SNMP port.
Overrides the port from the SNMP configuration for the interface.
| from SNMP configuration

| timeout
| SNMP timeout, in milliseconds.
Overrides the timeout from the SNMP configuration.
| from SNMP configuration

| retries
| Number of SNMP retries.
Overrides the retries from the SNMP configuration.
| from SNMP configuration

| forceVersion
| SNMP version to use instead of the configured one.
Valid values are `v1`, `v2c`, and `v3`.
| from SNMP configuration
|===

The detector reads the SNMP agent settings for the interface from the SNMP configuration.
The `port`, `timeout`, `retries`, and `forceVersion` parameters override them for detection only.

== Example configuration

The following detector finds the IP SLA operation tagged `FWL-PING`:

[source, xml]
----
<detector name="IP-SLA-FWL-PING" class="org.opennms.netmgt.provision.detector.snmp.CiscoIpSlaDetector">
    <parameter key="adminTag" value="FWL-PING"/>
</detector>
----
