= Memcached Detector
:description: Learn how the MemcachedDetector in OpenNMS {page-component-title} finds Memcached services for monitoring in your network.

The MemcachedDetector finds Memcached services for monitoring in your network.
It sends the `version` command to the configured TCP port and detects the service when the reply starts with `VERSION`.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.MemcachedDetector`
|===

== Configuration and use

The MemcachedDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the MemcachedDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port to connect to.
| 11211

| idleTime
| Time, in milliseconds, that the detector waits for data from the service before it gives up.
The value is rounded to whole seconds, with a minimum of one second.
| 3000

| useSSLFilter
| Set `true` to use TLS for the connection.
| false
|===

NOTE: This detector opens connections with a fixed connection timeout of 2000 milliseconds and does not apply the `timeout` parameter.
Use `idleTime` to control how long it waits for responses.

== Example configuration

The following detector finds Memcached services on the default port:

[source, xml]
----
<detector name="Memcached" class="org.opennms.netmgt.provision.detector.simple.MemcachedDetector">
    <parameter key="port" value="11211"/>
</detector>
----
