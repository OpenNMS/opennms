= NRPE Detector
:description: Learn how the NrpeDetector in OpenNMS {page-component-title} finds Nagios Remote Plugin Executor (NRPE) agents.

The NrpeDetector finds Nagios Remote Plugin Executor (NRPE) agents.
It sends an NRPE query with the configured command and detects the service when the agent returns result code `0`.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.NrpeDetector`
|===

== Configuration and use

The NrpeDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the NrpeDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port of the NRPE agent.
| 5666

| command
| NRPE command to run.
The default command asks the agent for its version.
| _NRPE_CHECK

| useSsl
| Set `false` to connect without TLS.
| true

| padding
| Number of padding bytes added to the NRPE packet.
| 2
|===

== Example configuration

The following detector finds NRPE agents that accept connections without TLS:

[source, xml]
----
<detector name="NRPE-NoSSL" class="org.opennms.netmgt.provision.detector.simple.NrpeDetector">
    <parameter key="port" value="5666"/>
    <parameter key="useSsl" value="false"/>
</detector>
----
