= Microsoft Exchange Detector
:description: Learn how the MSExchangeDetector in OpenNMS {page-component-title} finds Microsoft Exchange servers by their POP3 and IMAP banners.

The MSExchangeDetector finds Microsoft Exchange servers.
It reads the banners of the POP3 and IMAP ports, and detects the service when either banner contains `Microsoft Exchange`.
The detector does not use the `port` parameter.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.msexchange.MSExchangeDetector`
|===

== Configuration and use

The MSExchangeDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the MSExchangeDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| pop3Port
| TCP port of the POP3 service.
| 110

| imapPort
| TCP port of the IMAP service.
| 143
|===

== Example configuration

The following detector reads the banners of the default POP3 and IMAP ports:

[source, xml]
----
<detector name="MSExchange" class="org.opennms.netmgt.provision.detector.msexchange.MSExchangeDetector">
    <parameter key="pop3Port" value="110"/>
    <parameter key="imapPort" value="143"/>
</detector>
----
