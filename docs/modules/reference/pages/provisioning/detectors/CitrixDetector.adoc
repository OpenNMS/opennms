= Citrix Detector
:description: Learn how the CitrixDetector in OpenNMS {page-component-title} finds Citrix ICA services for monitoring in your network.

The CitrixDetector finds Citrix Independent Computing Architecture (ICA) services for monitoring in your network.
It connects to the configured TCP port and detects the service when the server banner starts with `ICA`.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.CitrixDetector`
|===

== Configuration and use

The CitrixDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the CitrixDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port to connect to.
| 1494

| idleTime
| Time, in milliseconds, that the detector waits for data from the service before it gives up.
The value is rounded to whole seconds, with a minimum of one second.
| 3000

| useSSLFilter
| Set `true` to use TLS for the connection.
| false
|===

NOTE: This detector opens connections with a fixed connection timeout of 2000 milliseconds and does not apply the `timeout` parameter.
Use `idleTime` to control how long it waits for responses.

== Example configuration

The following detector finds Citrix ICA services on the default port:

[source, xml]
----
<detector name="Citrix" class="org.opennms.netmgt.provision.detector.simple.CitrixDetector">
    <parameter key="port" value="1494"/>
</detector>
----
