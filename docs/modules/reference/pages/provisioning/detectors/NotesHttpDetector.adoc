= Notes HTTP Detector
:description: Learn how the NotesHttpDetector in OpenNMS {page-component-title} finds Lotus Notes HTTP services for monitoring in your network.

The NotesHttpDetector finds HTTP services, such as the HTTP task of a Lotus Domino server.
It sends an HTTP `HEAD` request for the configured URL and detects the service when the response starts with a valid HTTP status line.
If you set `checkRetCode` to `true`, the status code must also be the same as or lower than `maxRetCode`.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.netmgt.provision.detector.simple.NotesHttpDetector`
|===

== Configuration and use

The NotesHttpDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the NotesHttpDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| TCP port to connect to.
| 80

| url
| URL path to request.
| /

| checkRetCode
| If set to `true`, only HTTP status codes that are the same as or lower than the value of `maxRetCode` pass.
| false

| maxRetCode
| Highest HTTP status code that passes.
Evaluated only if `checkRetCode` is set to `true`.
| 399

| idleTime
| Time, in milliseconds, that the detector waits for data from the service before it gives up.
The value is rounded to whole seconds, with a minimum of one second.
| 3000

| useSSLFilter
| Set `true` to use TLS for the connection.
| false
|===

NOTE: This detector opens connections with a fixed connection timeout of 2000 milliseconds and does not apply the `timeout` parameter.
Use `idleTime` to control how long it waits for responses.

== Example configuration

The following detector requests `/names.nsf` and accepts status codes up to 302:

[source, xml]
----
<detector name="NOTES" class="org.opennms.netmgt.provision.detector.simple.NotesHttpDetector">
    <parameter key="url" value="/names.nsf"/>
    <parameter key="checkRetCode" value="true"/>
    <parameter key="maxRetCode" value="302"/>
</detector>
----
