= OpenManage Chassis Detector
:description: Learn how the OpenManageChassisDetector in OpenNMS {page-component-title} finds Dell OpenManage chassis status over SNMP.

The OpenManageChassisDetector finds Dell servers that report their chassis status through OpenManage over SNMP.
It reads the chassis status OID `.1.3.6.1.4.1.674.10892.1.200.10.1.4.1`, and detects the service when the value is between `1` (other) and `6` (non-recoverable).
Use it together with the xref:service-assurance/monitors/OpenManageChassisMonitor.adoc[OpenManageChassisMonitor].

== Configuration and use

The OpenManageChassisDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the OpenManageChassisDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| port
| SNMP port.
Overrides the port from the SNMP configuration for the interface.
| from SNMP configuration

| timeout
| SNMP timeout, in milliseconds.
Overrides the timeout from the SNMP configuration.
| from SNMP configuration

| retries
| Number of SNMP retries.
Overrides the retries from the SNMP configuration.
| from SNMP configuration

| forceVersion
| SNMP version to use instead of the configured one.
Valid values are `v1`, `v2c`, and `v3`.
| from SNMP configuration
|===

The detector reads the SNMP agent settings for the interface from the SNMP configuration.
The `port`, `timeout`, `retries`, and `forceVersion` parameters override them for detection only.

== Example configuration

The following detector finds Dell OpenManage chassis status with the default settings:

[source, xml]
----
<detector name="Dell-OpenManageChassis" class="org.opennms.netmgt.provision.detector.snmp.OpenManageChassisDetector"/>
----
