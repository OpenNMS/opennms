= RADIUS Authentication Detector
:description: Learn how the RadiusAuthDetector in OpenNMS {page-component-title} finds RADIUS authentication services.

The RadiusAuthDetector finds RADIUS authentication services.
It sends an Access-Request with the configured credentials and detects the service when the server answers with an Access-Accept, Access-Challenge, or Access-Reject.
Because a rejected request also counts as detected, the credentials do not have to be valid.
The server must accept requests from the {page-component-title} server with the configured shared secret.

== Detector facts

[options="autowidth"]
|===
| Implementation | `org.opennms.protocols.radius.detector.RadiusAuthDetector`
|===

== Configuration and use

The RadiusAuthDetector uses the xref:reference:provisioning/detectors.adoc#ref-detector-provisioning-common-parameters[common configuration parameters].

.Parameters for the RadiusAuthDetector
[options="header"]
[cols="1,4,1"]
|===
| Parameter
| Description
| Default

| authPort
| UDP port for authentication requests.
The detector uses this parameter instead of `port`.
| 1812

| acctPort
| UDP port for accounting requests.
| 1813

| secret
| Shared secret between {page-component-title} and the RADIUS server.
| secret

| authType
| Authentication method.
Valid values are `pap`, `chap`, `mschapv1`, `mschapv2`, `eapmd5`, `eapmschapv2`, and `eapttls`.
| pap

| user
| User name sent in the request.
| OpenNMS

| password
| Password sent in the request.
| OpenNMS

| nasID
| NAS identifier sent in the request.
| opennms

| innerIdentity
| Inner identity for EAP-TTLS authentication.
| Inner-OpenNMS

| ttlsInnerAuthType
| Inner authentication method for EAP-TTLS authentication.
| pap

| timeout
| Time to wait for a response, in milliseconds.
The value is converted to whole seconds, with a minimum of one second.
| 2000
|===

== Example configuration

The following detector finds RADIUS servers that share the secret `my-secret` with {page-component-title}:

[source, xml]
----
<detector name="RadiusAuth" class="org.opennms.protocols.radius.detector.RadiusAuthDetector">
    <parameter key="authPort" value="1812"/>
    <parameter key="secret" value="my-secret"/>
    <parameter key="authType" value="chap"/>
</detector>
----
