[[restore-centos-rhel8]]
.Restore user/group definition

[source, console]
----
cat /tmp/opennms-passwd.txt | sudo tee -a /etc/passwd > /dev/null && \
cat /tmp/opennms-group.txt | sudo tee -a /etc/group > /dev/null
----

.Create log folder
[source, console]
----
sudo mkdir /var/log/opennms && \
sudo chown opennms:opennms /var/log/opennms
----

.Restore OpenNMS {page-component-title} binaries, RRD archives, configurations

[source, console]
----
sudo tar -xzf /tmp/opennms-opt.tar.gz -C / && \
sudo tar -xzf /tmp/opennms-var.tar.gz -C /
----

.Create OpenNMS systemd unit
[source, console]
----
sudo cp /opt/opennms/etc/opennms.service /lib/systemd/system/
----

.Install PostgreSQL database

Install PostgreSQL as described in the CentOS/RHEL tabs of xref:deployment:core/install.adoc#setup-postgresql[Set up PostgreSQL].
You do not need to create the `opennms` database user or the database, because the database backup restores them.

.Restore OpenNMS database
[source, console]
----
sudo runuser -l postgres -c 'psql -f /tmp/opennms-postgres.dmp postgres'
----

.Install OpenJDK
[source, console]
----
sudo dnf -y install java-25-openjdk
sudo /opt/opennms/bin/runjava -s
----

.Run `install -dis` command
[source, console]
----
sudo /opt/opennms/bin/install -dis
----

.Firewall configuration

Depending on where OpenNMS gets restored, you need to set the firewall settings again.

See xref:deployment:core/centos/initialize-core.adoc#initialize-core-firewall[firewall settings] and xref:deployment:core/centos/firewall-core.adoc[firewall core].

.Start OpenNMS service
[source, console]
----
sudo systemctl start opennms
----
