[[restore-debian-ubuntu]]
.Restore user/group definition

[source, console]
----
cat /tmp/opennms-passwd.txt | sudo tee -a /etc/passwd > /dev/null && \
cat /tmp/opennms-group.txt | sudo tee -a /etc/group > /dev/null
----

.Create log folder
[source, console]
----
sudo mkdir /var/log/opennms && \
sudo chown opennms:opennms /var/log/opennms
----

.Restore OpenNMS {page-component-title} binaries, RRD archives, configurations

[source, console]
----
sudo tar -xzf /tmp/opennms-usr-share.tar.gz -C / && \
sudo tar -xzf /tmp/opennms-etc.tar.gz -C / && \
sudo tar -xzf /tmp/opennms-var-lib.tar.gz -C / && \
sudo tar -xzf /tmp/opennms-usr-share-java.tar.gz -C /
----

.Create OpenNMS systemd unit
[source, console]
----
sudo cp /etc/opennms/opennms.service /lib/systemd/system/ && \
sudo systemctl daemon-reload
----

.Install PostgreSQL database

Install PostgreSQL as described in the Debian/Ubuntu tab of xref:deployment:core/install.adoc#setup-postgresql[Set up PostgreSQL].
You do not need to create the `opennms` database user or the database, because the database backup restores them.

.Restore OpenNMS database
[source, console]
----
sudo runuser -l postgres -c 'psql -f /tmp/opennms-postgres.dmp postgres'
----

.Install OpenJDK
[source, console]
----
sudo apt-get install openjdk-25-jdk
sudo /opt/opennms/bin/runjava -s
----

.Run `install -dis` command
[source, console]
----
sudo /opt/opennms/bin/install -dis
----

.Start OpenNMS service

[source, console]
----
sudo systemctl start opennms
----
