.Add a repository and import a GPG key

Debian/Ubuntu::
+
--
.Download and import GPG key
[source, console]
----
sudo apt -y install gnupg ca-certificates
sudo wget -qO - https://debian.opennms.org/OPENNMS-GPG-KEY | sudo gpg --dearmor -o /usr/share/keyrings/opennms.gpg
----

.Add and update apt repository
[source, console]
----
sudo tee /etc/apt/sources.list.d/opennms.sources > /dev/null << "EOF"
Types: deb
URIs: https://debian.opennms.org/
Suites: stable
Components: main
Signed-By: /usr/share/keyrings/opennms.gpg
EOF
sudo apt update
----
