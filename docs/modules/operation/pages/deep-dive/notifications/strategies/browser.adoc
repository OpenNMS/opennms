
= Browser Notifications
:description: How the browser notification strategy in {page-component-title} shows notices as desktop notifications in a user's web browser.

The browser notification strategy shows a notice as a desktop notification in the browser of the targeted user.
It is the strategy behind the default `browser` command.

The strategy class is `org.opennms.netmgt.notifd.BrowserNotificationStrategy`.

Each user has to allow notifications in each browser they use, and notices reach only browsers that have an {page-component-title} page open at the time.
For the setup procedure and its limitations, see xref:operation:quick-start/notifications.adoc[Turn on Default Notifications].

== Default command

[source, xml]
----
<command binary="false">
  <name>browser</name>
  <execute>org.opennms.netmgt.notifd.BrowserNotificationStrategy</execute>
  <comment>Sending Notification to the Browser</comment>
  <argument streamed="false">
    <switch>-d</switch>
  </argument>
  <argument streamed="false">
    <switch>-subject</switch>
  </argument>
  <argument streamed="false">
    <switch>-tm</switch>
  </argument>
  <argument streamed="false">
    <switch>noticeid</switch>
  </argument>
</command>
----

== Arguments

[options="header"]
[cols="1,3"]
|===
| Switch
| Description

| `-d`
| User ID of the target; the notice is shown only in browsers where this user is signed in.

| `-subject`
| Title of the desktop notification.

| `-tm` or `-nm`
| Body of the desktop notification.
If the command declares both, the one listed last is used.

| `noticeid`
| Notice ID.
When present, clicking the desktop notification opens the notice.
If the value is not a positive number, the notification is shown without the link.
|===

The strategy has no properties file and always reports success to notifd, whether or not a browser displays the notice.
