NOTE: Debian does not install UFW by default.
To use the following commands, install it with `sudo apt install ufw` and enable it with `sudo ufw enable`.
Allow SSH (`sudo ufw allow ssh`) before you enable UFW on a remote system, or you might lose your connection.

.Enable Masquerade to allow port forwarding
[source, console]
----
sudo vi /etc/ufw/before.rules
----

.For TFTP forwarding, add the following lines at the top before the `*filter` section
[source, console]
----
*nat
:PREROUTING ACCEPT [0:0]
-A PREROUTING -p udp --dport 69 -j REDIRECT --to-port 6969
COMMIT
----

.Apply the firewall changes
[source, console]
----
sudo ufw allow in 69/udp
sudo ufw allow in 6969/udp
sudo ufw reload
----
